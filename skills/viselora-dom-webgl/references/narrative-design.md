# Narrative planning

Use narrative planning when the user asks for a new story or a visual redesign,
not as a prerequisite for a targeted technical migration.

For a new experience, identify the message, audience, key interactions and
available assets. Describe the meaningful sections with semantic DOM, visual
state, forward/reverse scroll behavior, mobile/reduced-motion alternatives and
an observable completion condition. Use as many sections as the content needs.

[The optional story plan](../templates/story-plan.md) records those decisions.
Preserve an existing approved design when the task only changes infrastructure.
