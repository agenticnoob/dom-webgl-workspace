# Hero Next 哑光灰白摄影棚纵深设计

**日期：** 2026-07-13
**状态：** 已确认，等待用户复核文档

## 目标

保留 `apps/hero-next` 的纯视觉四面体首屏，将当前单层灰白径向渐变升级为有明确前、中、后景关系的无缝摄影棚空间。整体颜色使用低反差的哑光灰白，不加入文字、导航、网格、建筑线框或高饱和色。

## 已确认方向

- 视觉语言：无缝摄影棚，而不是暗室、雾化展厅或几何建筑空间。
- 背景颜色：哑光暖灰白，避免纯白与蓝灰塑料感。
- 空间线索：弧形地平线、地面明暗过渡、主体下方柔和接触阴影、中心提亮和边缘轻压暗。
- 主体关系：四面体仍是唯一视觉主体；背景只负责承托和分离轮廓。
- 内容边界：不增加文案、按钮、导航、标识或装饰性物体。

## 视觉构成

空间由三个低对比层级组成：

1. 后景使用暖灰白渐变，中心比边缘略亮，四角只做轻微压暗。
2. 中景通过宽而柔的弧形地平线区分墙面与地面，不出现硬折线或可见房间边界。
3. 前景在四面体下方放置低透明度、宽模糊边缘的椭圆接触阴影，使主体看起来悬浮在空间中而不是贴在屏幕上。

基础色控制在 `#d2d1cd` 到 `#f0efeb` 的暖灰白范围。磨砂感来自极细、低透明度、单色噪声；噪声不得形成可识别纹理，也不得盖住阴影和主体边缘。

## 场景与组件边界

- CSS 负责页面加载期的灰白 fallback、中心光区、边缘压暗和细颗粒，避免 WebGL 尚未就绪时出现白闪。
- `hero.tetrahedron.scene` 继续拥有四面体、相机和灯光。
- 使用公开的 `WebGLStagePlane` 声明地面/背景承托层，不直接创建 Three.js scene、renderer、camera 或 material。
- 接触阴影使用受控 stage-plane effect 生成径向透明度，不依赖当前公开 API 尚未提供的实时阴影开关。
- 四面体继续使用现有 managed model effect；仅在浏览器证据表明轮廓分离不足时微调材质粗糙度和现有冷暖轮廓光。
- 保留默认 scene 为空，不修改 runtime/package 公共行为。

## 光照与材质

背景材质采用高粗糙度、低金属度的哑光表面。地面与背景色差保持很小，主要依靠亮度、角度和阴影建立纵深。

现有三灯结构保留：环境填充光保证暗面可读，两侧方向光分离四面体轮廓。灯光颜色向中性暖灰收敛，避免背景发蓝；高光保持柔和，不把黑色四面体变成镀铬物体。

## 动态与降级

- 背景、地平线和接触阴影保持静态，不闪烁、不呼吸。
- 四面体保留已有的轻微呼吸、漂浮和缓慢旋转。
- 接触阴影的中心位置与视觉主体对齐，但不做逐帧追踪；用足够宽软的范围容纳现有小幅漂浮。
- `prefers-reduced-motion: reduce` 下继续使用静态四面体构图，空间层次不依赖动画成立。
- GLB 或 Draco 加载失败时，灰白摄影棚背景仍完整可见。

## 响应式

- 桌面端显示完整弧形地平线和椭圆接触阴影。
- 宽度不超过 700px 时提高地平线位置、缩小阴影宽度，并沿用当前四面体缩放与垂直偏移规则。
- 任何尺寸下都不产生横向滚动，不让地平线穿过四面体视觉中心。

## 预计修改范围

- `apps/hero-next/src/HeroExperience.tsx`：声明背景/地面/阴影 stage planes，并保持 props 引用稳定。
- `apps/hero-next/src/heroEffect.ts`：增加静态接触阴影 effect；按浏览器结果小幅调整主体材质。
- `apps/hero-next/app/globals.css`：重构灰白 fallback 渐变、地平线和磨砂颗粒 token。
- `apps/hero-next/test/`：覆盖新增公开声明、稳定 effect registry、视觉 token 和 reduced-motion fallback。

## 验收标准

- 首屏明确读作暖灰白无缝摄影棚，而不是平面渐变或白色空页。
- 能同时感知背景、地面和主体三层关系，但看不到硬边房间结构。
- 四面体下方存在柔和接触阴影，主体仍保持轻微悬浮感。
- 灰白背景保持哑光、低对比，不发蓝、不纯白、不抢主体。
- 四面体始终是唯一主体，轮廓和各面在桌面与移动尺寸下可辨。
- 无首屏白闪、横向溢出、控制台错误或 reduced-motion 回退异常。
- hero-next 测试、类型检查、production build、导入边界检查和 `git diff --check` 通过。

## 范围外

- 文案、导航、CTA、品牌元素或新增页面章节。
- 实时物理阴影、runtime API 扩展或 raw Three.js 逃生口。
- 部署、发布或推送。
